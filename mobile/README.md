# Beat Slicer Mobile

Мобильная HTML5-сборка поддерживает iOS Safari и Android Chrome без установки приложения.
Для Android также собирается полноценный APK с игрой и всеми тремя треками внутри.

## Как играть

- **iPhone:** открыть опубликованную HTTPS-ссылку в Safari, выбрать трек и нажать START.
- **Android:** установить `dist/BeatSlicer-android.apk` и открыть Beat Slicer как обычную игру.

APK работает без интернета, запускается в полноэкранном режиме и перехватывает системный
Back, чтобы случайный жест назад не закрывал игру. Домашний системный жест Android намеренно
остаётся доступен — веб-приложение не должно запирать пользователя внутри себя.

## Файлы

- `mobile/beat_slicer_mobile.source.html` — редактируемый мобильный источник.
- `beat_slicer_mobile.html` — сгенерированный standalone-файл с тремя MP3 внутри.
- `tools/build_mobile.py` — детерминированная сборка data URI.
- `tools/build_android.py` — сборка подписанного APK без Android Studio.

Сборка:

```bash
python3 tools/build_mobile.py
```

Итоговый HTML автономен, но iOS Quick Look (экран с именем файла, крестиком и Share)
не является браузером и блокирует необходимый runtime. На iPhone игру нужно открывать
по HTTP/HTTPS-ссылке непосредственно в Safari. Для проверки по локальной Wi-Fi сети:

```bash
python3 tools/serve_mobile.py
```

Скрипт напечатает точный адрес для Safari. Интернет после загрузки не нужен. Из-за трёх
встроенных MP3 размер файла около 25.3 MiB.

Android-сборка (для разработчика):

```bash
python3 tools/build_android.py
```

Результат: `dist/BeatSlicer-android.apk`. Android SDK 35 и Java 17 должны быть установлены;
скрипт автоматически использует стандартные Homebrew-пути на macOS.

## Отличия мобильной версии

- Canvas работает в CSS-координатах с DPR, ограниченным 1.6 ради производительности.
- Положение шара считается аналитически от `AudioContext.currentTime`, поэтому пропуск
  кадров не меняет траекторию и момент вершины дуги.
- Если мобильный браузер разбудил вкладку слишком поздно и до удара осталось меньше
  безопасного времени полёта, цель пропускается без штрафа вместо сверхбыстрого запуска.
- При повороте экрана масштабируются исходные координаты, скорости и гравитация уже
  летящих целей; сетка времени не сдвигается.
- На touch-устройствах отключена hover-пауза, добавлены pointer capture/cancel.
- Управление закрепляется за первым активным `pointerId`; дополнительные пальцы
  игнорируются и не могут соединить две позиции ложным «лучом».
- Эквалайзер сокращён до 36 баров, число частиц уменьшено, DPR ограничен.
- `viewport-fit=cover` и safe-area учитывают вырезы и нижнюю системную панель.
- Неподдерживаемый на мобильных браузерах режим Tab Audio убран. Локальный Track file
  оставлен как дополнительный режим.

## Smoke-check

```bash
python3 tools/build_mobile.py
python3 -m py_compile tools/build_mobile.py
node -e 'const fs=require("fs"),h=fs.readFileSync("mobile/beat_slicer_mobile.source.html","utf8");new Function(h.match(/<script>([\s\S]*?)<\/script>/)[1])'
git diff --check
```

На реальном устройстве проверить обе ориентации, все три сложности всех трёх уровней,
возврат из background и финальный экран. Поздний device skip не должен начислять miss.
